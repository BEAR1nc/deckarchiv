GitHub-Verbindung

Damit „Auf GitHub speichern“ funktioniert, braucht diese Seite einmal pro Gerät einen Zugangsschlüssel (Token). Er bleibt nur in diesem Browser gespeichert.

  1. Auf GitHub: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Bei Repository access nur dein Deckarchiv-Repository wählen.
  3. Bei Permissions → Contents „Read and write“ einstellen, dann erzeugen und hier einfügen.
